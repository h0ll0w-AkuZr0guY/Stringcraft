# Windows 桌面使用与项目迁移

统一工作区从根目录的「启动弦作」打开。桌面作品和插件保存在 `data`，模型复用根目录的 `runtime`。桌面下载自动进入 `exports`，PDF 保存对话框也从这里打开。升级桌面程序时保留作品库和计算环境。独立便携发布包仍按下文运行。

0.2.1 本地试用包自带 CPU 分轨运行环境和实录钢琴音色。解压后从根目录启动 `Stringcraft.exe`，应用依赖集中在 `_internal`。有 NVIDIA 显卡时可在插件中心导入另行提供的 CUDA 离线 ZIP，签名文件 `.zip.sig` 放在 ZIP 同目录。自检通过后会切换运行环境。作品仍保存在当前 Windows 用户的数据目录。

插件中心可以打开 `plugins/inbox` 并扫描手动放入的签名插件 ZIP。钢琴跟练默认左手 `A S D F G`、右手 `J K L ; '`。吉他用左手选和弦、右手方向键扫弦，`H J K L ; '` 对应六弦到一弦。旧键位和旧改键可以从预设菜单选回。

六线谱进入全屏后可打开 A4 预览，使用「适合整页」「适合宽度」和 Ctrl＋滚轮。打印六线谱沿用预览分行。五线谱加六线谱可通过「节奏谱」打开。

完整解压后双击 Stringcraft.exe。Windows x64 桌面应用使用系统 WebView2 Runtime。如果系统缺少它，安装 Microsoft 的 x64 Evergreen 离线运行时并重新启动。[微软安装说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)

## 第一次上手

1. 打开时可直接用“林间来信”试生成，也可以上传音频、MIDI 或 MusicXML。
2. 常规模式默认“弹唱伴奏”和“日常”。从三个目标、四档难度中独立选择，点“生成吉他编配”。六线谱会自动显示新结果，播放条可以直接试听。
3. 音符、六线谱、节奏谱共享播放位置。点击音符可试听或从该处继续播放。拖动播放进度、切谱面与缩放都会定位当前小节。手动滚动可暂停跟随，点“回到播放位置”恢复。
4. 可一键全屏读谱，Ctrl＋滚轮缩放。也可以选择钢琴生成双手谱或进入键盘练习。
5. “专业模式”打开整页设置。这里可选择扫弦或分解、转录方式、节拍与和弦、指法校正，以及用于 A/B 的“乐句实验”。返回谱面或切换常规模式时保留设置。

## 托盘、本地分轨与迁移

- 点击窗口右上角关闭，暂停播放并缩到托盘。分析和生成任务继续运行。双击托盘图标或再次启动应用恢复原窗口，试听从原位置手动续播。
- 托盘“退出弦作”会等待作品保存并结束本地任务和服务。托盘“打开数据目录”可查看当前保存位置。全局设置中可直接选择包含 local-separation 的 runtime_plugins 目录，重启后生效。
- 已安装模型环境时，HTDemucs 先分离人声与伴奏。伴奏和单线练习使用器乐，指弹按需转录独立人声。专业模式的“识别与分轨”会显示设备和模型状态。未安装独立环境时可使用内置基础识别。详见 [运行扩展](MUSIC_RUNTIME.md)。
- 从旧浏览器版本打开作品，选“导出含音频工程”，然后在桌面版“我的作品 → 导入项目”选 ZIP。没有音频可迁移时使用项目 JSON。浏览器与桌面各自保存数据，旧作品仍留在原处。
- 在“导出”菜单选择“打印六线谱 PDF”，桌面版直接选文件路径。节奏谱的打印按钮保留乐谱专用排版。

复杂混音的原始识别和自动编配都需要校订。乐句实验的适用范围与回归记录见 [质量记录](QUALITY.md)。
