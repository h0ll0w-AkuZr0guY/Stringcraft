# Stringcraft 本地试用

此包仅供本地测试，版本 0.2.0-local.2。没有发布到 Pages 或 GitHub Release。

## 启动

完整解压 ZIP，双击 Stringcraft.exe。请保留同目录的 _internal 和其他文件，程序会打开本机浏览器。启动窗口保持打开；关闭它会停止服务。再次双击同一版本会打开现有窗口。

主界面顶部显示版本和构建标识。默认地址为 http://127.0.0.1:18765/。如果端口已被旧版本或其他程序使用，会提示先关闭旧程序，不会悄悄打开旧页面。无需安装 Node、Python 或额外模型环境。

完整模型包已附带分离与和弦模型、Python 和 FFmpeg；基础识别、分离、编配、音符试听和导出使用包内资源，可以断网测试。AI 建议默认关闭，基础流程不需要 Key。仅下载基础 preview 包时不含重模型，请区分文件名。

## 推荐测试顺序

1. 在音符编辑器点击“用原创音频体验真实识别”，查看结果并点击音符试听。
2. 点“送往吉他编配”，这个单旋律短句先选“单线旋律练习”和难度，再点“生成吉他编配”。
3. 观察按钮旁的阶段和耗时；完成后会定位到谱面，点“播放结果”。失败时会保留旧谱并给出处理入口。
4. 尝试你的音频；必要时展开高级校正确认节拍、和弦及声部。无可靠和弦时，可先选择单线旋律练习。
5. 导出 MIDI、WAV 和项目 JSON，再重开项目检查保存结果。

插件提示需要更新或启用时，可点击“修复所需插件”，修复后重新生成。此操作只处理生成必需项，不修改项目材料。旧项目可创建 v2 副本，原项目保留。

项目和录音缓存在当前浏览器的本机地址下，清理浏览器数据会删除它们。请导出项目备份；项目 JSON 不包含录音。诊断导出只包含版本、参数、阶段及错误，不包含 Key、音频或完整音符。

## 反馈

优先描述：使用的版本、点了哪个按钮、看到什么状态、预期结果。失败时可导出诊断信息。本地测试和可见操作录屏只证明流程；复杂混音识别、吉他可演奏性与听感仍需逐曲核对。

## 完整模型版

本包附带独立 Python、CUDA Torch、HTDemucs 和 BTC 和弦网络，以及 Basic Pitch ONNX 权重。在“识别方式”中明确选择“本地伴奏增强（实验）”。检查完成后会显示 CUDA/CPU 实际设备；初次探测可能需要几秒。增强仍有逐曲退化，因此默认保留基础模式，不自动声称达到准确率门槛。

增强完成后，可以试听分离伴奏、分离低音，并选择分离后网络、原曲网络、基础音符证据三个和声方案。切换方案后重新生成吉他谱。改 BPM 只调整记谱与节奏，不重复分离、不删除秒时间轴和弦。所有模型激活值均非经过校准的正确概率。BTC 当前仅识别大小三和弦及无和弦，扩展和弦需人工校订。

插件中心只列五个用户能力包，开发示例和内部模块不再充数。完整运行库体积明显增大，复制时必须保留 runtime_plugins 文件夹。使用前请关闭旧版本。
