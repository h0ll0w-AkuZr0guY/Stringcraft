# 隐私与网络请求

基础识别、编配、试听和导出在浏览器执行。项目和安装插件存于 IndexedDB；音频可保存在此浏览器用于重开原曲对照。导出项目仅包含音乐数据和配置，不含原音频、API Key 或模型身份信息。清除网站数据可删除浏览器记录；请先备份项目。

录音关联在本机计算完整文件 SHA-256，项目文件可包含该摘要、解码时长和对照起点，用于核验重新选择的文件。摘要不包含音频内容，但可用于识别同一文件，分享项目时请知悉。撤销可恢复先前关联，因此旧录音缓存保留到删除该作品或清除网站数据。

首次加载应用、模型、WASM、样本与插件会访问 Pages 静态站点；Pages 的基础访问日志遵循 GitHub 政策。默认不安装访问分析或遥测。无需登录。

AI 建议默认关闭。用户开启后，浏览器把 Key 与必要摘要直接发给所填 HTTPS Endpoint；不经过维护者服务器。只发送难度、音符数量和候选变调夹/评分，不发送歌曲文件名、音频或逐音序列。Key 仅存页面内存，不写入 IndexedDB。仅向自己信任的服务地址输入 Key，API 请求可能计费。

本地任务输入发送至自己的 127.0.0.1 服务。上传副本结束时删除，结果存于本机 Stringcraft/jobs。模型权重可能首次联网下载；完整环境包可预置权重。程序不代用户分享音频。

浏览器插件包含可执行代码，摘要校验用于发现损坏与版本不匹配，不是恶意代码隔离。首版只提供维护者审阅的官方目录，不能自行添加任意远程插件来源。
