# 使用指南

## 整曲音符编辑器

默认进入音符编辑器。上传音频自动识别，无需先生成吉他谱。可逐音试听、拖动校订、筛选和导出，完整操作及限制见 [音符编辑器](NOTE_EDITOR.md)。上限为 5 分钟 / 50 MB，停止任务保留已完成的部分。初始原创曲是预先编写，页面底部“用原创音频体验真实识别”则确实运行模型。

## 吉他片段工作台

打开在线地址即可使用。首次界面展示“林间来信”原创示例，它是预先编写的音符，用于体验编配和编辑。示例没有经过识别。上传自己的音频，才会启动 Basic Pitch Worker。

支持浏览器能解码的 MP3/WAV/FLAC 等文件，视频取决于浏览器格式支持。在线上限 50 MB；选择起点和 1–60 秒片段。默认 30 秒。速度候选来自起音间隔，可能出现半速/倍速歧义；请在“音乐结构”确认节拍，或轻拍至少三次定速。模型载入失败会报错，不替换成演示音符。

启用“波形节拍候选”插件后，音乐结构会显示独立波形候选。点“试听拍点”可听原曲叠加滴答声，再点“使用速度”采用参考 BPM；它不会自动改写默认速度，也不移动原始音符。候选拍点起点可用于核对，首个完整小节仍需结合乐句确定。相同演奏可能支持半速或倍速记谱，不能只挑最高分。

MIDI 可导入音符与首个速度。MusicXML 支持未压缩 score-partwise 的独立声部、休止、延音线、连奏关系、速度/拍号图及常见和弦性质；装饰音、反复展开和复杂记谱需人工核对，不支持 MXL/PDF/图片。PDF 打印是导出能力，不能代替识谱。

## 编配与校谱

常规模式在主视图直接选择目标、难度并生成，反馈显示阶段与耗时。失败时继续保留上次结果。专业模式打开横向铺满的设置页，包括编配、识别与分轨、节拍与和弦、音符与指法。播放条保留在上方。操作步骤见 [本地试用](LOCAL_TRIAL.md)。

清晰吉他录音可勾选“清理弱音候选（实验）”，下次分析时减少相对弱的候选音。它可能漏掉和弦中的弱音，默认关闭；项目始终保留原始候选，并另存清理后的候选及原因。本地混音乐默认先分离，快速浏览器识别需显式选择。

先选择目标：和弦伴奏适合弹唱，独奏指弹保留旋律与结构低音，单线旋律用于练习。四档均可用于任一目标。改变目标保留难度，改变难度保留目标。伴奏可选扫弦或分解，完整六弦和弦按实际指型验证，不按同时音符数量定义难度。自动变调夹比较当前编配的实际指型候选，手动 0 品有效。

伴奏节奏型按小节推进，换和弦不会重新从第一拍开始。3/4 与 6/8 使用各自的拍组；短和弦区间若没有节奏起音，会保持休止并提示。改速度后重新生成，估计和弦会依据当前弱起、拍号和网格重新计算，人工和弦优先保留。

在“音乐结构”校正和弦，问号表示估计结果；每小节可添加换和弦位置。未确定的区间保持空白，没有和弦证据时伴奏会提示补充。可指定导入声部的旋律、低音或内声部用途；确认的材料会优先保留，原谱弦品在可演奏时沿用。检测残留不会自动成为支持声部。旧项目请点击“升级为 v2 副本”，原项目继续保留。

点击六线谱数字试听并定位；在专业模式校订起音、时长、弦或品位。修改后自动锁定，重新编配保留。锁定音与新难度或变调夹冲突会提示，需要先解锁或调整。删除操作可撤销；重新生成可能重新引入被删除的自动音符。永久保存当前结果请导出项目。

音符编辑中可选择独立拨弦、击弦、勾弦、滑音或闷音。连奏要求前一个同弦音与当前起音相接，且方向、弦位与手指约束通过；不满足时保留原结果并提示。× 表示闷音，试听使用短噪声近似，MIDI 使用打击乐侧击音替代。它与休止、普通低音分别保存。

六线谱按小节排列，数字列保留最小间距；密集片段在谱面内部横向滚动。可显示左右手指法，箭头表示扫弦方向。节奏谱按独立声部显示延音与连奏，和 MusicXML/TXT 一样近似量化到十六分网格。品位相对变调夹。WAV 和 MIDI 保留秒时间，不能仅按文字网格判断节奏。MusicXML 导出取实际编配，而非未编配的候选。

六线谱连奏线跨小节时显示延续箭头。节奏谱使用四分、八分、附点等时值，必要时再拆延音；指法可单独打开。“打印六线谱 PDF”输出图形谱，“打印节奏谱 PDF”在新窗口按 A4 重新排版，请在打印对话框选择另存 PDF。MusicXML 按吉他常规写高八度并声明移调，导回后实际音高不变。

## 试听与保存

播放编配或原曲对照，可以设循环范围和 0.5×/0.75×/1×。编配慢速不改变音高；原始录音慢速使用浏览器播放速率，会改变音高。若项目没有原始音频，“原曲对照”明确提示缺少源文件，不会用候选音合成代替。

钢弦、尼龙使用实录单音样本；没有匹配样本时回退合成，并显示计数。连奏沿用同一次发声激励过渡音高；此为采样/合成近似，效果不等同真实现场演奏。WAV 导出包含末尾释放时间，原始事件时序不变。

项目自动保存在本地应用配置或当前网页的 IndexedDB。用“我的作品 → 导入项目”迁移 ZIP 或 JSON，详细步骤见 [本地试用](LOCAL_TRIAL.md)。项目文件不包含 Key 或原始音频。原始音频副本可保留在当前浏览器用于重开对照，不会上传到维护者服务器。

换浏览器或重开备份后，可以点播放器中的“关联录音”，无需再次识别。浏览器分析会记录输入文件的 SHA-256；重新选择同一文件时核验为原文件，其他录音标为参考录音。旧项目未记录摘要时只能标为参考。调整“对照起点”可对应另一个演奏版本的起始位置，录音必须覆盖整个片段；不会移动谱面或原始识别时间，也不自动拉伸不同版本的速度。锁定指法和校谱结果保留。升级旧项目时，录音一并复制到新项目；删除作品会清除它在此浏览器中的全部关联录音。

## 百炼建议

API 设置填写 Key、对应地域的 Endpoint 与已开通模型。默认 qwen-plus，可自行调整。仅在开启 AI、自动推荐变调夹并点击生成时调用；不填 Key 可完成全部基础流程。发送难度、音符数量和候选统计，不发送音频或完整音符列表。Key 只在当前页面内存，刷新后需重新填写。

鉴权失败检查 Key 与地域是否匹配；429 检查额度；网络/跨域失败可关闭 AI，或使用本地工作台。模型返回不能越过本地候选验证；界面只显示本地评分与候选选择，不采信模型自行编写的数值比较理由。

## 本地增强

下载基础包完整解压并运行 Stringcraft.exe。增强环境包的 runtime_plugins 放在同目录，重启后，上传区域会出现本地整曲、分离人声、分离伴奏选项。单文件上限 200 MB，最多 30 分钟；建议先用短片段。分离与人声单音提取不保证主旋律准确，也不能自动识别原曲吉他技法。

安装环境前看 BUILDING 中的模型下载和第三方许可说明。本地只监听 127.0.0.1；不要改成公网地址。任务可取消，输入副本结束后删除。结果在本机应用数据目录保留，重启时清理超过一天的旧任务目录。

## 排查

- 无法解码：转换为 WAV，或使用本地 FFmpeg。
- 模型加载失败：检查网络、浏览器是否禁用 WASM、插件是否启用；重新安装 Basic Pitch。
- 结果杂乱：缩短片段、选择主旋律突出的部分，或本地分离人声后重试。
- 生成音符很少：降低移调幅度或放宽难度，查看音域限制；不要用增加噪声候选掩盖问题。
- 本地增强不可用：检查目录结构、插件 Python 和 FFmpeg；普通 venv 不可直接作为可移植包。
- 数据存储失败：立即导出项目，检查隐私模式与网站存储配额。

## 多轨本地工作台

上传后，本地模型先分离；左侧选择原曲、人声、伴奏或吉他编配。低音、鼓和其他器乐默认收起。上方播放条统一控制所有视图；暂停后续播，回到开头才重新开始。选择轨道音频、当前轨音符或多轨混合，独听/静音与音量变更会保留播放位置。伴奏包含低音和鼓，和这些子轨同时混合会重复叠加，按需要选择。

点音符会试听并定位，正在播放时从那里继续；拖动修改只编辑。六线谱空白位置可定位，节奏谱按实际渲染位置选择节拍或单音。手动滚动暂时关闭跟随，用“回到播放位置”恢复。

“编配与分析设置”放弹奏目标、手法、难度与高级音乐结构。“筛选”和“属性”按需打开。生成始终在主视图按钮发起，进度、取消和结果只有一个入口。指弹首次生成按需分析已分离人声，扫弦与分解不会等待该步骤。

跨机器保存请用“导出 → 导出含音频工程”，导入也用上传入口。JSON 仅含谱面和引用，不能携带 stem；旧项目原有 ID 和编辑保留。

## 0.2.0 读谱、钢琴与跟练

点击「全屏读谱」后可以 Ctrl＋滚轮缩放，A4 预览用于检查纸面排版，Esc 返回当前工程。全局设置可改变文字大小；作品卡片可改名、配色、标记和置顶。

桌面版在工作台选择钢琴，导入 MIDI、MusicXML 或清晰钢琴独奏后生成双手谱。右手和左手分别显示在双谱表上。扫弦、分解、指弹与单线仍在吉他插件。详细键位和练习模式见 [键盘练习](PRACTICE.md)。
