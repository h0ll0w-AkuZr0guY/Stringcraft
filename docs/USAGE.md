# 使用指南

## 基础工作台

打开在线地址即可使用。首次界面展示“林间来信”原创示例，它是预先编写的音符，用于体验编配和编辑。示例没有经过识别。上传自己的音频，才会启动 Basic Pitch Worker。

支持浏览器能解码的 MP3/WAV/FLAC 等文件，视频取决于浏览器格式支持。在线上限 50 MB；选择起点和 1–60 秒片段。默认 30 秒，参考速度暂设 120 BPM，请按实际音乐调整。模型载入失败会报错，不替换成演示音符。

MIDI 可导入音符与首个速度。MusicXML 当前支持未压缩 score-partwise 的音高、时长、休止、基本和弦和速度；复杂连音、变速、多声部与反复需人工核对，不支持 MXL/PDF/图片。PDF 打印是导出能力，不能代替识谱。

## 编配与校谱

四档难度限制同时声部、最高品位、跨度、起音间隔和换把速度。初学最多一个持续音，日常两个，进阶三个，挑战四个。算法优先保留旋律，再使用输入候选中的伴随音。变调夹自动推荐优先保留原调；手动 0 品有效。

点击六线谱数字编辑起音、时长、弦或品位。修改后自动锁定，重新编配保留。锁定音与新难度或变调夹冲突会提示，需要先解锁或调整。删除操作可撤销；重新生成可能重新引入被删除的自动音符。永久保存当前结果请导出项目。

图形六线谱按秒展示，持续横线表示时长；节奏谱和 TXT 按十六分网格近似量化。品位相对变调夹。WAV 和 MIDI 使用真实事件时间，不能仅按文字网格判断节奏。

## 试听与保存

播放编配或原曲对照，可以设循环范围和 0.5×/0.75×/1×。编配慢速不改变音高；原始录音慢速使用浏览器播放速率，会改变音高。若只导入项目而未提供源音频，“原曲对照”只能播放项目候选音，无法恢复原始录音。

钢弦、尼龙使用实录单音样本；没有匹配样本时回退合成，并显示计数。效果不等同真实现场演奏。WAV 导出包含末尾释放时间，原始事件时序不变。

项目自动保存在此浏览器 IndexedDB，清除网站数据会删除。导出 .stringcraft.json 备份，通过“我的作品”导入。项目文件不包含 Key 或原始音频。原始音频副本可保留在当前浏览器用于重开对照，不会上传到维护者服务器。

## 百炼建议

API 设置填写 Key、对应地域的 Endpoint 与已开通模型。默认 qwen-plus，可自行调整。仅在开启 AI、自动推荐变调夹并点击生成时调用；不填 Key 可完成全部基础流程。发送难度、音符数量和候选统计，不发送音频或完整音符列表。Key 只在当前页面内存，刷新后需重新填写。

鉴权失败检查 Key 与地域是否匹配；429 检查额度；网络/跨域失败可关闭 AI，或使用本地工作台。模型返回不能越过本地候选验证。

## 本地增强

下载基础包完整解压并运行 Stringcraft.exe。增强环境包的 runtime_plugins 放在同目录，重启后，上传区域会出现本地整曲、分离人声、分离伴奏选项。单文件上限 200 MB，最多 30 分钟；建议先用短片段。分离与人声单音提取不保证主旋律准确，也不能自动识别原曲吉他技法。

安装环境前看 BUILDING 中的模型下载和第三方许可说明。本地只监听 127.0.0.1；不要改成公网地址。任务可取消，输入副本结束后删除。结果在本机应用数据目录保留，重启时清理超过一天的旧任务目录。

## 排查

- 无法解码：转换为 WAV，或使用本地 FFmpeg。
- 模型加载失败：检查网络、浏览器是否禁用 WASM、插件是否启用；重新安装 Basic Pitch。
- 结果杂乱：缩短片段、选择主旋律突出的部分，或本地分离人声后重试。
- 生成音符很少：降低移调幅度或放宽难度，查看音域限制；不要用增加噪声候选掩盖问题。
- 本地增强不可用：检查目录结构、插件 Python 和 FFmpeg；普通 venv 不可直接作为可移植包。
- 数据存储失败：立即导出项目，检查隐私模式与网站存储配额。
