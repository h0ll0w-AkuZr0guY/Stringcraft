# 贡献与协作

欢迎提交可复现的音乐问题、插件、文档与测试。提交前阅读 AGENTS、架构和公共接口。

Issue 说明版本、浏览器/系统、输入来源类别、实际行为、期望行为和最短复现步骤。优先使用原创或合成短片段，勿上传无授权歌曲、Key 或私人谱件。旋律错误请区分音高、起音、延音、主声部选择与指法问题。

PR 聚焦一个行为。标题建议 `type(scope): 简短说明`；正文写问题、最终行为、兼容影响、实际验证与限制。公共接口变更同步文档和调用者，保留他人原作者及未提交改动。功能优先放插件，框架变更需说明现有 SDK 为什么无法表达。

普通贡献运行 npm run check 与相关测试。构建、打包见 BUILDING。纯文案不要求照抄实现增加测试；音乐规则必须覆盖关键不变量和对应失败案例。

AI 贡献按同样标准审查：指出引用的接口与测试，不以编造试听、未运行的模型或合成数据冒充实际验证。普通 CI 不调用付费 API。新增模型需说明权重来源、许可证、硬件条件、下载大小与离线方式。

变更追加到 UNRELEASED，正式历史在 RELEASES。正常功能 PR 不覆盖历史发布包，不提交环境、exe、ZIP、缓存或个人信息。维护者发布授权与版本标签分开记录，自动发布流程只处理通过检查的明确版本。
