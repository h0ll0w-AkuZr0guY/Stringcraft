# 质量与验证

当前为预览版。工程可运行与音乐可用性分别验收，不以成功生成文件替代听感、识别正确率和真人试弹。

0.2 后续验收按用户选择采用真实曲谱对照与约束校准为主，详见 [真实曲谱评估](REFERENCE_EVALUATION.md)。实际试弹可补充，不作为当前交付阻塞项；下方首版门槛和历史记录保留，不能将其理解为已完成证明。

## 0.2 开发验证

新增原创双声部 MusicXML 短谱，覆盖延音/连奏/休止/变速/变拍往返；新增和弦指型、四指、横按、持续占用、声音激励和间距回归。独立标准读取器接受导出的 MusicXML。具体发布缺口见 [音乐开发验收](MUSICAL_DEVELOPMENT.md)。以下 0.1 合成模型与实曲流程记录不作为新版实曲准确率。

## 固定样本

scripts/generate-fixtures.py 生成 12 段原创合成音频与精确音高/起音标注：升降音阶、重复、延音、低/高音、跳进、柔和起音、低音/持续垫底混合及静音。它们不是专业真实录音，也不是流行歌曲基准。tests/fixtures/audio/truth.json 是真值，生成规则可复现。

音乐单元测试覆盖四档指法约束、延音与同音重弹、capo/transpose、锁定保留、音域、省略、连续旋律、项目校验和基础导出。Playwright 使用真实音频上传，启动真实 WASM 模型，并测试校谱、插件与保存流程。

模型评估按同音高且起音误差不超过 50 ms 一对一匹配，报告 precision/recall/F1；另报 100 ms 作为诊断，不替代正式门槛。静音误报独立报告。新旧版本使用同一输入、相同阈值和模型环境，不能混用旧截图或历史统计。

## 正式质量门槛

1. 干净单旋律样本匹配 F1 达到 0.90。
2. 真实混音主旋律 F1 中位数较冻结旧版至少提升 0.10；单项下降超过 0.05 需处理或缩小能力声明。
3. 三段初学、三段进阶编配经吉他演奏者试弹，记录节奏、换把、跨度与听感反馈。
4. 锁定编辑、音符时间与导出往返无实质回归；全部硬指法约束通过。

上述真实混音比较与真人试弹尚不能由代码自测证明。未完成时只发布 preview，不标成稳定版，不宣传整曲高准确率。当前算法不可靠地推断拍号、和弦功能或原曲技法；网页 BPM 暂由用户校正。

## 可重复运行

生成样本后运行 npm run test:e2e；模型评估通过 scripts/evaluate-browser.mjs 执行，保存 JSON 和 Markdown 到 artifacts/quality。只把经过审阅的汇总写入此文档，私人音频和原始识别结果留在忽略目录。脚本区分浏览器模型指标与编配规则指标，不做自动“已达宣传效果”的结论。

## local.2 伴奏和声实验

新增 88 项单元回归、10 项后端检查、25 项普通浏览器流程通过；6 项需显式语料或 Key 的测试跳过。秒时间轴回归确认 68.5 与 135.7 BPM 产生同一和弦时间范围，原始音符不变。授权录音前 30 秒的真实本地界面运行取得 309 个原始音符、18 段和声区间；两种 BPM 均能生成非空伴奏，分离伴奏/低音可播放，WAV 非静音，三种和声方案可切换，重复输入复用缓存，任务可取消。事件数量随伴奏节奏改变不代表识别内容改变。

本机 RTX 4060 Ti 实际执行 HTDemucs 与 BTC CUDA 推理，Basic Pitch 使用 ONNX CPU；另实际跑通 CPU 分离路径。设备和权重摘要保存在项目分析记录。流程通过不代表听感或可演奏性已经通过真人验收。

冻结 BTC 只识别大小三和弦及 N。六段真实 GuitarSet 评估包含明显漏识别和分离后退化，未通过逐曲质量门槛，详见 [参考评估](REFERENCE_EVALUATION.md)。因此增强为主动选择的实验模式；没有上线训练，也没有将合成样本成绩解释为商业混音识别准确率。
