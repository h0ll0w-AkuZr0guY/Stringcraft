# 发布记录

## 0.2.1

- 六线谱支持 A4 分页、调弦和变调夹信息、和弦指型、扫弦方向与延音，桌面可以直接导出 PDF。
- 钢琴跟练提供左右手分区与宽音域预设，吉他分别设置和弦、扫弦和逐弦键。钢琴试听和 WAV 导出可用两档力度的 Salamander 实录音色。
- 桌面支持签名插件收件箱、安装验证与版本回退。开发维护可启用统一工作区，集中保存作品、导出和共享运行环境。
- Windows 核心包和音乐运行扩展分别维护。Pages 提供常规编辑和原创试玩。

已有作品可直接打开。旧版用户可在插件中心更新「标准吉他」，以使用新版扫弦规则。

## 0.2.0

Windows 桌面版加入全屏读谱、字号、作品卡片、钢琴双手谱和键盘练习。核心 ZIP 可独立运行，随附 SHA-256。CPU 与 CUDA 独立扩展见 [安装说明](MUSIC_RUNTIME.md)，初始安装与模型初始化需要联网。GitHub Pages 提供常规工作台与两种乐器的原创试玩。详见 [使用指南](USAGE.md) 和 [质量记录](QUALITY.md)。

## 0.2.0-preview.1 · 2026-11-23

默认入口改为整曲复音编辑器：上传自动分块识别，点击试听、拖动与精确校订、无损筛选、撤销重做，以及无需编配的 MIDI/WAV/项目导出。新增独立卷帘、通用音源与 MIDI 插件，原有吉他工作台保留。

同步交付 0.2 音乐结构、和弦伴奏/指弹目标、吉他动作与技法、节奏谱/打印、参考评估和录音关联。仍为预览，实曲准确率与真人试弹未通过稳定版门槛。本地纠错记录已实现，模型训练、钢琴双手和踏板为下一阶段。实际验证见 [音符编辑器](NOTE_EDITOR.md)，旧 Windows 0.1 下载包不会随 Pages 自动更新。

## 0.1.0-preview

从 Manus 本地原型重建为浏览器优先的吉他工作台。加入共享音乐 SDK、官方独立插件、Basic Pitch Worker、旋律连续性追踪、分级指法、编辑与锁定、保存、试听和导出。增加本地隔离计算协议、环境包构建及 AI 开发文档。

这是工程预览发布。合成样本验证、真实模型流程与自动检查的实际记录见 QUALITY；复杂真实歌曲与真人试弹尚未完成，不承诺宣传视频中的音乐效果已经达到。
