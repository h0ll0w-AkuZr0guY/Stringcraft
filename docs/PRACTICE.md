# 键盘练习

GitHub Pages 的「键盘试玩」提供原创钢琴和吉他小节。先开启参考音听一遍，也可切换自由弹奏。桌面版的插件中心可导入完整版官方签名 ZIP，开启当前作品练习、等弹对、详细反馈、选段循环和自定义键位。

## 钢琴

导入 MIDI、MusicXML 或清晰钢琴独奏录音，在乐器里选钢琴并生成双手谱。MusicXML 写定谱表优先。谱面可点击试听，可导出钢琴 MIDI 或双谱表 MusicXML。标为待核对的音仍会显示。

跟练默认左手从 C3 开始，右手从 C4 开始。默认自然音分别是 Z X C V B N M 和 Q W E R T Y U，升降音见琴键。完整版可以独立移动左右手八度，键区外会提示。点击琴键也可发声。

## 吉他

按 1 至 8 选择和弦，选择会保持到下一次换指型。J 下扫，K 上扫，U I O P [ ] 对应 1 至 6 弦。指板显示当前弦位，横向提示显示下一次拨弦或扫弦。更多和弦可切换一组，完整版可在练习设置改键。

## 两种跟练

按拍跟练会继续走谱，反馈精准、良好、命中、偏早、偏晚、漏弹与多弹。可设速度、范围、循环和延迟校准。等弹对会停在当前音组，按完要求的键推进，并显示首次正确率与重试。结果可定位到小节，作品音符保持独立保存。

练习中点击键盘区域可恢复键盘焦点，输入表单时键位映射关闭。无声时先点击「开始跟练」或「开始弹奏」激活音频。
