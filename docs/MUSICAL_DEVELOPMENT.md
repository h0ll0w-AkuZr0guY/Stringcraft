# 0.2 音乐编配改造与验收

当前为开发中的实现，尚未发布 0.2。0.1 公开预览的可运行性不能证明编配适合真人。以下要求来自对真实吉他编配问题的审查，未完成项不能被测试数量替代。

## 目标和边界

先选择和弦伴奏、独奏指弹或单线练习，再选择技术档位。四个快捷档默认：初学为简化和弦伴奏，日常为普通弹唱伴奏，进阶与挑战为单人指弹。挑战增加技法表达，不要求音符数比进阶多。

和弦伴奏从已确认或待核对的和弦进行及稳定节奏型生成。无依据的识别残留不再作为附加声部。指弹先保护旋律与结构低音，后续再完成内声部与段落变化。缺少可靠和声时留白并提示校正。

## 实曲评估协议

每个片段记录录音版本、起止秒、参考谱版本、目标类型、调弦、变调夹、拍号、首拍位置和速度。原曲录音、弹唱伴奏参考、指弹改编参考分别记录，不能相互当真值。每类至少前奏、主歌、副歌各 8 小节；另选非同曲素材作留出验证。

音高/起音/延音/重复激励、拍点误差、和弦区间覆盖、动作可行性分别评估。合成数据只验证确定性音乐语义。没有人工标注的真实音频只报告流程和诊断统计，不能报告识别准确率。真人记录每小节的速度、换把、跨度、持续声部、右手冲突和听感问题，至少三段伴奏与三段指弹完成实际试弹。

公开测试只收录原创或获授权素材。私人音频、完整商业歌曲谱和 API Key 不进入 Git、CI 或 Release。

## 结构参考

- [音伴《晴天》简化弹唱教学](https://www.yinban.com/tab/sing/5026.html)：关注保留共同手指、减少换指和稳定扫弦型；不复制付费全谱。
- [Steven Law 原站指弹改编谱](https://stevenlawguitar.com/wp-content/uploads/2015/11/e699b4e5a4a9.pdf)：关注前奏、和弦与独立低音/旋律声部；改编谱不当成原录音逐音真值。
- [MusicXML 记谱基础](https://www.w3.org/2021/06/musicxml40/tutorial/notation-basics/)与[六线谱技法](https://www.w3.org/2021/06/musicxml40/tutorial/tablature/)：延音、图形连线和演奏技法分别表达。

## 给接手 AI 的顺序

先读 AGENTS、架构和公共接口；查看本表的缺口，再从最小失败短句开始。优先补乐句与段落、和弦内声部和可验证的指法准备，随后对同一批实曲完成分阶段评估。不得以调大密度、删掉难例、复用原先的合成 F1，或将算法检查改名为真人验收来通过发布门槛。
