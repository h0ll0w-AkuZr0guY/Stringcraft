# 路线图

| 阶段 | 当前交付 | 尚需完成的验收 |
| --- | --- | --- |
| P0 基线 | 旧项目保留、有效规则转成测试、12 段合成样本 | 合法真实混音标注与旧版冻结比较 |
| P1 底座 | SDK v1、安装与恢复、项目保存、AI 开发文档、CI | 后续接口演进继续保持兼容 |
| P2 在线 | 真实模型片段识别、旋律追踪、吉他校谱、试听与导出 | 长期跨设备与大型项目表现 |
| P3 增强 | 本地进程协议、分离/识别插件、便携包构建 | 真人试弹、复杂歌曲质量门槛 |
| P4 发布 | GitHub/Pages/预览 Release 流程 | 满足正式质量门槛后升级稳定版 |

后续按以下顺序推进：

1. 吉他质量：重复音起音、主旋律保留、乐句与拍点、编辑屏蔽记录、更准确的手位与技巧。
2. 乐器适配：尤克里里、贝斯、钢琴；每种均需能力发现、编辑/谱面适配、演奏约束与测试，不能仅有清单。
3. 识谱：MusicXML 完整往返，再增加 PDF/图片的 OCR/OMR 插件，保留原图位置与人工修正。
4. 浏览器增强：按实测资源预算接入分离/更强旋律模型。保持可取消，优先扩大在线实际能力。
5. 插件生态：增加能力动态选择、通用 UI 扩展槽、资源校验缓存和版本迁移；第三方来源必须有独立信任设计。
